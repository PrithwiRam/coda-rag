CORE INNOVATIONS DELIVERED:
---------------------------

1. RETRIEVAL COMPUTATION PLANNER (RCP) — Central Innovation
   - LinUCB Contextual Bandit that learns optimal execution plans per-query
   - 8 discrete plan space: strategy (bm25/dense/hybrid) × depth × rerank × budget × compression × fallback
   - Online learning: updates arm weights via multi-objective reward after each query
   - Replaces all hand-crafted routing rules with learned adaptive policy

2. MOSAIC (Multi-Objective Submodular Adaptive Information Curation) — Replaces ACOA
   - Formal multi-objective submodular optimization over 6 objectives:
     * Relevance (semantic similarity)
     * Diversity (1 - redundancy)
     * Redundancy penalty (Jaccard overlap)
     * Token efficiency
     * Position-aware attention bias (primacy/recency)
     * Query-specific coverage
   - Greedy (1-1/e) approximation guarantee with lazy evaluations
   - Query-conditioned weights via RCP plan

3. QUERY ENCODER — Rich Feature Extraction
   - 15-dimensional feature vector: structural, linguistic, semantic, complexity
   - spaCy linguistic analysis (entities, POS, dependency depth, question type)
   - SentenceTransformer embeddings for semantic features
   - Outputs context vector for RCP bandit

4. CONFIDENCE PREDICTOR — Learned Quality Estimation
   - MLPClassifier (32-16 hidden) replacing static threshold gate
   - Features: top score, score gap, score std, coverage, result count, avg score, entropy, query length
   - Trainable on labeled retrieval quality data

5. REWARD COMPUTER — Multi-Objective Optimization Signal
   - Composite reward: α·quality + β·latency_score + γ·token_score
   - Configurable weights (default: 0.6 / 0.2 / 0.2)
   - Feeds RCP bandit for online adaptation

6. EXECUTION PLAN — Structured Action Space
   - 8 pre-defined plans covering retrieval strategies, depths, reranking, budgets
   - Each plan: strategy, retrieval_depth, rerank, rerank_depth, token_budget, compression, fallback
   - Cost estimation for resource-aware selection

================================================================================
PIPELINE FLOW (ACORA v2)
================================================================================

Query → QueryEncoder → RCP (selects plan) → Retrieval (per plan.strategy) 
    → Conditional Reranker (if plan.rerank) → ConfidencePredictor 
    → MOSAIC (plan.token_budget, plan.mosaic_weights) 
    → LLMGenerator → RewardComputer → RCP.update()

RESEARCH CONTRIBUTIONS ACHIEVED (vs. Original Proposal)
================================================================================

| Original Component          | ACORA v2 Replacement              | Novelty Gain                    |
|----------------------------|-----------------------------------|---------------------------------|
| Query Classifier (rule)    | QueryEncoder + RCP (learned)      | Bandit-based adaptive routing  |
| BM25/Dense/Hybrid Retrieval| RCP-selected strategy per query   | Online policy learning         |
| Cross-Encoder Reranker     | Conditional (plan.rerank)         | Budget-aware computation       |
| Confidence Gate (3 rules)  | ConfidencePredictor (MLP)         | Learned quality estimation     |
| ACOA (greedy relevance)    | MOSAIC (submodular multi-obj)     | Formal approx. guarantees      |
| Static token budget        | Plan-conditioned budget           | Resource-aware optimization    |
| No feedback loop                       NEW   | RewardComputer + RCP.update()     | End-to-end RL loop             |
